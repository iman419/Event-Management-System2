# Update AI Log Skill

## Purpose
Keep `docs/AI_LOG.md` accurate and up to date throughout the Event Management System project.

## Instructions
- Read the existing `docs/AI_LOG.md` before editing it.
- Record the AI tools used, tasks performed, and important prompts or requests.
- Summarize what the AI generated or changed.
- Record at least two **real, verified** cases of incorrect or poor AI output for each milestone, as required by the project instructions.
- For every case, explain what the AI got wrong, how the problem was noticed, and how it was corrected.
- Never invent mistakes, tests, results, prompts, or tool usage.
- If two real cases have not yet occurred, clearly mark them as pending and update the log when actual cases arise.
- Keep entries organized by milestone.
- Preserve existing accurate information.
- Use simple, clear language.
- Save the updated content to `docs/AI_LOG.md`.
- After editing, summarize what was added and identify any information that still needs verification.
